# Voice-to-text corrections.
#
# The notebook was dictated by a cold, exhausted, starving guy, so the phone
# mangled a lot of army vocabulary. These rules produce the "Cleaned" reading
# mode. The raw text in journal.txt is never modified -- both versions ship and
# the reader toggles between them.
#
# Format:   regex ||| replacement          (# starts a comment line)
# Rules run in order, so put specific ones above general ones.
# Every change is logged to source/CHANGES.txt -- review it after building.
#
# DELIBERATELY NOT FIXED, because the error says something the correction loses:
#   "I confessed about lost"      -- the phone censored "lust"
#   "I tried so hard to sniff"    -- "snuff", in a poem about being undone by a smell
#   "Gowdre"                      -- how the drill sergeant actually said his name
#   "WANDE holy shit dude WANED"  -- him fighting the dictation in real time
#   "TARDS", "raffle Grapple"     -- same
#   "press barbarian" asides      -- he's talking to the transcription itself
