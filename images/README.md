# images/

Scans and photos of the doodles go here.

Name them after the slot they fill — `p5-1.jpg`, `p35-1.png` — then register them
in `data/art.js`:

```js
window.ART = {
  "p5-1": { src: "images/p5-1.jpg" },
};
```

The slot id is printed on every empty drawing slot in the journal, so you can just
say "here's p35-1" and it goes straight in.

Phone photos are fine. Anything wider than ~1600px is bigger than it needs to be.
